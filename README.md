# CourseMatch — рекомендация образовательных курсов для ИТ-ролей

Исследовательский проект: подбор образовательных курсов под требования рынка труда
к конкретным ИТ-специальностям.

> Статус: проектирование и разработка. Рабочий прототип в процессе создания.

Репозиторий: https://github.com/hoffnungslosAllein/it-course-recommender

## О проекте

Выбор курса для освоения профессии обычно опирается на маркетинговые описания и
субъективные рекомендации. При этом требования работодателей к одной и той же роли
достаточно устойчивы и измеримы: если навык встречается в большинстве вакансий
определённой специальности, он действительно важен для этой роли.

Проект решает обратную задачу: сначала из массива реальных вакансий строится
взвешенный профиль компетенций ИТ-роли, затем из описаний образовательных курсов
извлекается набор формируемых компетенций, после чего курсы ранжируются по степени
покрытия требований роли.

Проект выполняется в рамках выпускной квалификационной работы. Использование
некоммерческое, исследовательское.

## Что делает система

**Вход:** название ИТ-роли (например, Backend Python, Data Scientist, QA Automation)
и параметры фильтрации.

**Выход:** ранжированный список курсов, для каждого из которых указывается:

- оценка релевантности роли;
- компетенции роли, которые курс покрывает;
- компетенции роли, которые курс не покрывает;
- ссылка на курс.

## Как это работает

1. Сбор вакансий ИТ-специалистов из открытых источников.
2. Очистка текстов и удаление дубликатов.
3. Извлечение профессиональных навыков и их нормализация по каноническому словарю.
4. Построение взвешенного профиля компетенций роли на основе множества вакансий.
5. Сбор образовательных курсов и определение формируемых ими компетенций.
6. Сопоставление профиля роли с компетенциями курса.
7. Расчёт релевантности, ранжирование и формирование рекомендаций.
8. Экспериментальная оценка качества рекомендаций.

### Модель оценки

Значимость навыка `s` для роли `r` определяется долей вакансий этой роли, в которых
навык встречается:

```
w(r, s) = |{вакансии роли r, содержащие s}| / |{вакансии роли r}|
```

Релевантность курса `c` для роли `r` — взвешенная доля покрытых требований:

```
score(r, c) = Σ w(r, s) для s ∈ S(c) ∩ S(r)  /  Σ w(r, s) для s ∈ S(r)
```

где `S(r)` — множество навыков профиля роли, `S(c)` — множество навыков курса.

## Источники данных

| Данные | Источник | Статус |
|---|---|---|
| Вакансии | API hh.ru | доступ по токену приложения, заявка подана |
| Образовательные курсы | API Stepik | доступен без авторизации |

Обрабатываются только открытые публичные данные о вакансиях и курсах.
Персональные данные соискателей не запрашиваются и не используются.

## Технологии

- Python
- SQLite — хранение собранных и обработанных данных
- pandas — анализ данных
- sentence-transformers — семантическое сопоставление навыков
- scikit-learn — вспомогательные алгоритмы и оценка результатов
- requests — работа с API

## Структура проекта

```
skillrec/
  collect/      сбор данных из внешних источников
  extract/      извлечение и нормализация навыков
  profile/      построение профиля компетенций роли
  match/        сопоставление роли и курсов
  recommend/    ранжирование и формирование рекомендаций
  eval/         экспериментальная оценка
data/           собранные данные и словарь навыков
config.yaml     конфигурация
```
